- A server deployed with `mcpl_deploy` now gets the environment every boot-loaded server gets. That includes the refusal-reaction baseline, `DISCORD_SUPPRESSED_REACTIONS_BASELINE`, as a default its own env can override, which a deployed Discord adapter used to start without. `mcpl_deploy` refuses an entry the boot would skip as malformed, such as an `env` that isn't a map of text, rather than saving it. `mcpl_unload` saves the overlay before it disconnects, with nothing awaited between reading the file and writing it. So a change landing during the disconnect is no longer overwritten, and an unload asked to persist is recorded even when the disconnect fails, which its receipt says.
